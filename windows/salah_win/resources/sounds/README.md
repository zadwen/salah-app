Place a short notification sound here named `adhan_beep.wav`
(or point Settings → Sound → Choose Sound File at any .wav/.mp3/.ogg
elsewhere on disk -- .mp3/.ogg require the optional `playsound`
package, .wav always works via the built-in `winsound` module).

No sound file is bundled here for licensing reasons -- please use a
beep tone or an adhan clip you have rights to. `.wav` is recommended
as the default since it needs zero extra dependencies on Windows.
